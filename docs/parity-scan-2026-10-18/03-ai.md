# 03 · AI 抽象层、协议与媒体 —— Parity 扫描（2026-10-18）

- 参考实现：`/opt/opencode-ref`（TypeScript，opencode v2.0.24，`packages/ai/**` + `packages/core/src/aisdk*.ts`、`packages/core/src/github-copilot/**`）
- 目标实现：`/opt/opencode-rust`（`crates/oc-ai/**`；provider 运行时接线在 `crates/oc-core/src/provider_catalog/**`、`crates/oc-core/src/integration/**`，属本子系统的事实组成部分，一并纳入）
- 方法：只读逐文件映射 + 关键行为面（鉴权头、URL 拼接、请求字段、流式分帧、usage/cache、reasoning、tool-call 组装、错误/重试分类、abort、媒体上传/轮询）grep 定位比对；测试覆盖以 expected-dump 管道与 cassette 回放为证据。
- 严重度：**S0** = 主链路功能中断/挂死；**S1** = 单个 provider/协议/媒体后端功能错误或缺失（用户可感知）；**S2** = 边缘行为、元数据、测试覆盖缺口。

## 0. 总览

| 维度 | 结论 |
|---|---|
| 代码量 | ref `packages/ai` src ≈31k LOC（protocols 14.8k + utils 2.3k + providers 4.5k + route 3.1k + schema 1.7k + 根 3.6k）；rust `oc-ai` src ≈51.7k（含内联测试），运行时接线 oc-core/provider_catalog ≈4.5k |
| 架构差异（有意） | ref 是「每 provider 一个 facade 模块 + 通用协议」；rust 把 provider 差异折叠进两处：① oc-ai 协议内的 route 构造器/overlay（`openai_chat.rs` 内 deepseek/groq/openrouter/venice/zai/alibaba；`anthropic_messages.rs` 内 kimi/moonshot/xiaomi/minimax 检测）；② oc-core `provider_catalog/facade.rs` 的 package→ProtocolFamily 分发。行为目标是等价的，但等价性依赖 URL/provider 嗅探（`detect_max_tokens_field`/`detect_supports_store`/`detect_supports_strict_mode`/`detect_zai_tool_stream`，`openai_chat.rs:1689-1775`），非静态 wiring |
| 已验证的核心 parity | anthropic-messages、openai-chat（6 个 fixture 组）、openai-responses、open-responses（4 组）、gemini、cohere、mistral、bedrock-converse、vertex、copilot 均有以「真实 v2 状态机生成的 expected dump 逐事件匹配」或 cassette 回放为证的测试（`tests/anthropic_messages_parity.rs`、`tests/responses_parity.rs`、`tests/body_parity.rs`、`src/test_support.rs`） |
| 最大的洞 | ① WS 通道整体 deferred（openai-responses 的 v2 **默认**传输）；② 媒体 route 执行层（`route/media.ts`+`media-protocol.ts` 779 LOC）缺失且无任何运行时消费者；③ cohere/mistral 原生协议存在但**未接线**；④ Azure 部署 URL/鉴权头缺失；⑤ HTTP 超时预算未实现；⑥ Bedrock SigV4 无 AWS 默认凭证链 |
| KNOWN 占比 | WS/media-route/experimental/generateObject/sanitize/aisdk.sdk 均有文档化登记（ai-map §10、FINDINGS、lib.rs 注释）；**超时预算、cohere/mistral 接线、mantle responses defaults、azure URL、google-speech、google-interactions、xai-responses 适配等为本扫描 NEW** |

严重度计数：S1 × 12，S2 × 14（详见 §2/§3/§4/§5）；无确定性 S0（超时预算缺失最接近，见 §5.1）。
